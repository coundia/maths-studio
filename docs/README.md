# Documentation - Math3D Studio

Bienvenue dans le dossier de documentation de **Math3D Studio**. 

Ce répertoire a vocation à contenir toute la documentation technique et fonctionnelle liée au projet.

## Contenu

Actuellement, voici la structure recommandée pour la documentation :
- **Architecture** : Décrit l'architecture technique (frontend React, Vite, Tailwind CSS, backend Express).
- **Règles Agents** : Le fichier `AGENTS.md` situé à la racine du projet contient les règles de conception primordiales.
- **Base de données / Stockage** : La logique du stockage basé sur des fichiers JSON dans le répertoire `data/`.
- **Intégration MathLive** : Les explications sur l'utilisation du composant `math-field` pour le tableau interactif WYSIWYG.

*Ce fichier sera mis à jour au fur et à mesure du développement du projet.*
